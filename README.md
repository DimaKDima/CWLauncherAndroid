# CWLauncher для Android

Лаунчер Minecraft Java Edition для сервера Common World. Это мобильная версия CWLauncher: тот же сценарий входа, загрузки клиента и запуска игры, что и у лаунчера для Windows.

Версия приложения: **3.5.10**.

## Что умеет

- Вход через Ely.by и офлайн-аккаунт.
- Загрузка Minecraft, Fabric, ресурсов и библиотек.
- Установка сборки модов Common World.
- Новости, список обновлений и статус сервера.
- Настройки внешнего вида: фон, затемнение и размытие.
- Встроенная Java 17 для запуска игры на arm64.

Сервер Common World: `commonworld.pterohost.ru`.
